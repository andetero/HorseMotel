Support

Need help with the HorseMotel.com app or want to report a listing issue? This page provides quick support options and guidance.

Get support

For app support or listing concerns, contact HorseMotel.com by email. Include the listing name, location, and a short description of the issue so it can be reviewed.

Email Support Visit HorseMotel.com

Before you travel

Always contact the facility directly before arrival. Listings can change, and facility owners should confirm availability, pricing, stall or paddock details, directions, and current conditions.

Common app questions

  • Use search or the state filter to narrow the listings.
  • Use the map style selector to switch between standard, satellite, and hybrid views.
  • Use the heart icon to save a listing for later.
  • Use the report icon on a listing to email a listing issue.

Location and maps

The app may request location permission so it can show nearby listings and center the map around your current location. You can change this permission in your device settings.

Listing source

HorseMotel.com remains the official website and source of truth for listings. Listings are provided by HorseMotel.com and used with permission.
